# 来源质量评估标准

## 评估维度

### 1. 权威性 (Authority)
| 等级 | 标准 | 示例 |
|------|------|------|
| A | 原始来源、官方发布、同行评审 | 政府统计局、顶会论文、官方文档 |
| B | 专业机构、知名媒体、行业报告 | 咨询公司报告、权威媒体 |
| C | 一般媒体、个人博客、论坛 | 需交叉验证 |
| D | 匿名来源、未验证内容 | 原则上不采用 |

### 2. 时效性 (Timeliness)
| 等级 | 标准 |
|------|------|
| A | 1年内（技术/市场类）；5年内（学术类） |
| B | 2-3年内（技术/市场类）；5-10年（学术类） |
| C | 超过3年（技术/市场类）；超过10年（学术类） |
| D | 无日期或明显过时 |

### 3. 相关性 (Relevance)
| 等级 | 标准 |
|------|------|
| A | 直接回答研究问题 |
| B | 提供重要背景或上下文 |
| C | 间接相关，需要推理关联 |
| D | 弱相关或离题 |

### 4. 客观性 (Objectivity)
| 等级 | 标准 |
|------|------|
| A | 平衡呈现多方观点，无显著偏见 |
| B | 有立场但论据充分、透明 |
| C | 明显倾向性，需对照阅读 |
| D | 宣传性/煽动性内容 |

## 最低采纳标准
- 综合评分 >= B级方可采纳
- 单一C级来源需有至少一个A/B级来源交叉验证
- D级来源原则上不采纳

## 偏见标记
- 商业利益：由商业实体发布的竞品对比
- 政治立场：政府/党派背景来源的政策相关论述
- 行业立场：行业协会发布的行业数据
- 个人偏见：个人观点浓厚的分析文章
