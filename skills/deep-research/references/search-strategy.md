# 搜索策略模板

## 策略制定步骤

### 1. 问题分解
将研究问题分解为子问题：
```
主问题: [原始问题]
子问题1: [具体维度A]
子问题2: [具体维度B]
子问题3: [具体维度C]
```

### 2. 关键词矩阵
| 子问题 | 核心关键词 | 同义词/变体 | 限定词 |
|--------|-----------|------------|--------|
| 子问题1 | keyword1 | alt1, alt2 | filter1 |
| 子问题2 | keyword2 | alt3, alt4 | filter2 |

### 3. 搜索轮次设计

**第一轮：广度扫描**
- 目标：了解全貌，识别关键概念和主要来源
- 方法：通用关键词，宽泛搜索
- 输出：概念地图、候选来源池

**第二轮：深度钻取**
- 目标：针对关键子问题深入搜索
- 方法：精确关键词组合，限定域名/时间
- 输出：专题证据集

**第三轮：验证补充**
- 目标：验证关键发现，填补信息缺口
- 方法：反向搜索（以关键发现为关键词）
- 输出：验证记录、补充证据

### 4. 源优先级
```
1. 官方/原始来源（文档、论文、法规）
2. 权威机构（研究机构、国际组织）
3. 专业媒体（行业垂直媒体）
4. 综合媒体（主流新闻）
5. 社区/论坛（仅作线索）
```

### 5. 搜索记录格式
```
| 轮次 | 关键词 | 平台 | 结果数 | 采纳数 | 备注 |
|------|--------|------|--------|--------|------|
```
