# Spreadsheet Model Skill

## 目的
构建结构化的数值分析模型，支持计算、假设情景分析和数据可视化。

## 触发条件
- 任务涉及数值计算、财务分析或数据建模
- 需要假设情景或敏感性分析
- 交付物需要表格/电子表格格式

## 输入
- 数据或数据来源
- 模型逻辑和公式需求
- 假设参数和变量
- 输出格式要求

## 输出
- 结构化模型定义（表格结构、公式、参数）
- 假设情景设定
- 结果摘要

## 工作流
1. 定义模型结构和输入/输出关系
2. 设定假设参数和变量
3. 编写公式和计算逻辑
4. 设计假设情景
5. 输出模型定义和结果

## 不负责
- 不生成实际的.xlsx文件（仅输出结构化定义）
- 不做数据采集（由deep-research或用户提供）
- 不替代code-builder做复杂算法实现
