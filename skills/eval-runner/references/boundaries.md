# Eval Runner 边界

## 适用范围
- Skill回归测试
- 基准建立
- 性能退化检测
- 自动化质量门控

## 不适用场景
- 用户任务的实时交付审查（由quality-review负责）
- 主观创意评估
- 非结构化输出评估
- 运行时代码调试

## L1→L2→L3演进
| 级别 | 能力 | 触发条件 |
|------|------|---------|
| L1 | 结构校验+硬条件+回归 | 每次更新后 |
| L2 | +语义相似度+人类评估对接 | 月度评估 |
| L3 | +A/B测试+自动调优建议 | 季度评估 |

## 自动化规则
- 结构校验可100%自动化
- 硬条件检查可100%自动化
- 回归检测可100%自动化
- 语义评估需人工介入或模型评估

## 红线
- 评估结果必须诚实，不因期望而调整
- 失败归因必须具体到可修复的层面
- 评估标准变更必须显式记录
