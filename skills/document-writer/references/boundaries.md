# Document Writer 边界

## 适用范围
- evidence-synthesis输出已就绪
- 需要生成书面交付物
- 任务单明确需要报告/文档

## 不适用场景
- 证据尚未完成synthesis
- 纯代码/数据交付物（无报告需求）
- 已有现成文档仅需微小修改

## 输入质量检查
- [ ] Claim-Evidence Map存在
- [ ] 至少包含1个High或2个Medium置信度Claim
- [ ] 引用链完整
- [ ] 不确定性已标注

## 写作红线
- 不编造数据支撑论点
- 不删除已标注的冲突
- 不将假设包装为事实
- 不添加与输入无关的内容
- 不使用"根据常识"等无来源支撑语

## 长度约束
| 报告类型 | 建议长度 | 章节数 |
|---------|---------|--------|
| 简要摘要 | 500-1000字 | 3-4 |
| 标准报告 | 2000-5000字 | 5-6 |
| 深度报告 | 5000-10000字 | 6-8 |
| 白皮书 | 10000字+ | 8+ |
