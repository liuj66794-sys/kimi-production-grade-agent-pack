# Code Builder Skill

## 目的
根据需求编写高质量代码，包含测试、文档和最佳实践。

## 触发条件
- 任务单需要代码交付
- 需要实现算法、脚本或应用
- 需要代码审查或重构

## 输入
- 功能需求或规格说明
- 目标语言和框架
- 约束条件（性能、兼容性等）
- 现有代码（如为重构任务）

## 输出
- 源代码
- 测试用例
- 代码文档/注释
- 部署/运行说明

## 工作流
1. 分析需求，设计代码结构
2. 编写核心功能代码
3. 编写测试用例
4. 编写文档和注释
5. 自检代码质量

## 不负责
- 不做需求分析（由task-intake和swarm-orchestrator完成）
- 不做基础设施部署（仅提供代码和说明）
- 不替代product-builder做产品规划
