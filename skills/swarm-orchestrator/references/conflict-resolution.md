# 冲突解决策略

## 冲突类型

### Type A: 事实冲突
- 定义：不同Agent对同一事实给出矛盾陈述
- 处理：
  1. 追溯原始来源
  2. 判断来源可信度（时效性、权威性）
  3. 标记为待验证，优先采信高可信度来源
  4. 无法判断时保留多方观点并标注不确定性

### Type B: 结论冲突
- 定义：基于相同事实得出不同结论
- 处理：
  1. 分析推理路径差异
  2. 检查假设前提
  3. 标记推理分歧点
  4. 呈现多种推理可能性

### Type C: 范围冲突
- 定义：不同Agent对任务边界理解不一致
- 处理：
  1. 回顾原始任务单
  2. 以任务单为准裁定
  3. 要求超出范围的Agent收缩
  4. 要求未覆盖的Agent补充

### Type D: 格式冲突
- 定义：输出格式不兼容导致无法整合
- 处理：
  1. 指定统一格式标准
  2. 要求重新格式化
  3. 或由Orchestrator做格式转换

## 冲突清单模板
```
| ID | 类型 | 涉及Agent | 冲突描述 | 解决策略 | 状态 |
|----|------|----------|---------|---------|------|
| 1  | A    | A1, A2   | ...     | ...     | open |
```

## 升级规则
- 1-3个冲突：Orchestrator直接解决
- 4-6个冲突：标记需要人工review节点
- 7+个冲突：暂停执行，请求用户澄清原始需求
