# Swarm Orchestrator 边界

## 适用范围
- task-intake标记为swarm的任务
- 需要多Agent协作的复杂任务
- 涉及多领域知识整合的任务

## 不适用场景
- 单工具/单步骤可完成的任务
- 已明确单一Agent可处理的任务
- 纯闲聊或非结构化对话

## 复杂度阈值
| 指标 | swarm阈值 |
|------|----------|
| 信息源数量 | >= 5个独立来源 |
| 输出格式 | >= 3种不同格式 |
| 专业领域 | >= 2个不同领域 |
| 执行阶段 | >= 3个明显阶段 |
| 文件数量 | >= 5个独立文件 |

## 控制原则
1. **最小 swarm**：能用2个不用3个，能用sequence不用parallel
2. **依赖显式化**：所有依赖必须显式声明，禁止隐式依赖
3. **结果可审计**：每个Agent输出必须可追溯、可验证
4. **失败隔离**：单Agent失败不扩散，可重试或降级
