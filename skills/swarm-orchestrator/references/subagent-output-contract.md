# 子Agent输出契约模板

## 契约结构

每个子Agent必须明确以下契约项：

### 1. 输出格式
```
- 格式类型: [structured-data / report / code / list / summary]
- 结构模板: [指向具体模板或示例]
- 编码要求: [utf-8 / json / markdown / 其他]
```

### 2. 必填字段
```
- [ ] 字段A: 说明
- [ ] 字段B: 说明
- [ ] 字段C: 说明
```

### 3. 质量标准
```
- 完整性: 必须覆盖的范围
- 准确性: 可验证标准
- 粒度: 详细程度要求
```

### 4. 禁止事项
```
- 禁止添加未经验证的事实
- 禁止跳过指定结构
- 禁止暴露内部模块名称
```

### 5. 交付截止时间
```
- 相对顺序: [第N个交付]
- 依赖条件: [依赖的其他Agent输出]
```

## 契约验证
Orchestrator在收集结果时验证：
1. 格式合规性检查
2. 必填字段完整性
3. 质量标准达标判断
4. 禁止事项红线检查

## 违约处理
- 格式不合规 → 要求重新格式化
- 字段缺失 → 要求补充
- 质量不达标 → 要求补充材料或重新执行
- 触碰红线 → 标记为fail并记录
