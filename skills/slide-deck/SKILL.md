# Slide Deck Skill

## 目的
将结构化内容（如报告、分析结论）转化为适合演示的幻灯片格式。

## 触发条件
- 任务单需要幻灯片/PPT格式交付
- 内容需要面向观众演示
- 需要故事线驱动的视觉呈现

## 输入
- 来自document-writer的结构化报告或evidence-synthesis的结论
- 目标受众和演讲时长
- 品牌/风格要求（如有）

## 输出
- 幻灯片大纲和页面内容
- 演讲者备注
- 可选：演示脚本

## 工作流
1. 分析内容结构，提取核心论点
2. 设计故事线和页面流程
3. 分配每页内容（标题、要点、视觉建议）
4. 编写演讲者备注
5. 输出结构化幻灯片定义

## 不负责
- 不生成实际的.pptx文件（仅输出结构化定义）
- 不做新的研究或分析
- 不替代document-writer做内容创作
