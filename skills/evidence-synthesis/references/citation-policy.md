# 引用策略与格式 v1.2

## 1. 引用原则

1. **可追溯**：每个引用必须能追溯到具体来源和位置
2. **上下文保留**：引用需保留足够的上下文，避免断章取义
3. **利益相关**：标注来源的利益相关性和潜在偏见
4. **时效标注**：标注信息的获取时间和来源发布时间
5. **透明冲突**：v1.2新增 - 冲突来源必须显式呈现，不得隐藏反对证据

## 2. 引用格式规范

### 2.1 Inline Citation（行内引用）

用于正文中简短标注来源。

```markdown
格式: [来源编号:位置标记]

示例:
- [S3:第2节] —— 来源S3的第2节
- [S5:p.42] —— 来源S5的第42页
- [S1:表3,行2-5] —— 来源S1表3的2-5行
- [S7:图A] —— 来源S7的图A
- [S2,S4,S8] —— 多来源合并引用
```

**使用场景**：
- 单个事实陈述后的来源标注
- 短段落（<100字）的主要证据来源
- 数值、日期等具体数据的出处

### 2.2 Footnote（脚注引用）

用于需要额外说明的引用。

```markdown
格式:
正文内容[^1]，更多内容[^2]。

[^1]: [S3] 作者.标题.平台,日期. 质量:A. 偏见:无. 获取时间:2024-01-15.
[^2]: [S5] 作者.标题.平台,日期. 质量:B. 偏见:可能偏向甲方. 获取时间:2024-01-15.
```

**使用场景**：
- 需要说明来源质量的引用
- 来源存在已知偏见需要标注
- 同一来源多次引用且需要详细说明

### 2.3 Endnote（尾注引用 / 来源清单条目）

用于报告末尾的完整来源清单。

```markdown
格式:
[S{序号}] {作者/机构}. {标题}. {发布平台}, {发布日期}.
质量评级: {A/B/C/D/E/F}. 偏见标记: {如有}. URL: {链接}.
获取时间: {YYYY-MM-DD}. 归档链接: {如有}.
```

**完整示例**:
```
[S1] 国家统计局. 2024年一季度国内生产总值初步核算结果. stats.gov.cn, 2024-04-16.
质量评级: A. 偏见标记: 无（官方数据）. URL: https://www.stats.gov.cn/...
获取时间: 2024-04-20. 归档链接: https://archive.md/...

[S3] Zhang et al. "The Impact of AI on Labor Markets". Journal of Economics, 2024.
质量评级: B. 偏见标记: 无（同行评审）. URL: https://doi.org/...
获取时间: 2024-05-10.

[S5] Goldman Sachs. Global Economics Analyst: AI Investment Outlook. 2024.
质量评级: C. 偏见标记: 可能偏向投资银行业务推广. URL: ...
获取时间: 2024-06-01.
```

### 2.4 多重引用（多来源合并）

当多个来源共同支撑同一结论时：

```markdown
格式选项:

选项A - 支持/反对分离:
[支持: S3, S5; 反对: S7]

选项B - 带权重说明:
[强支撑: S1(A级), S3(A级); 弱支撑: S5(C级); 反对: S7(D级)]

选项C - 带一致性说明:
[S3, S5, S8: 结论一致 —— "AI将提升生产率"]
[S7: 反对 —— "影响被高估"]
```

**多来源合并规则**：
- 2-3个来源使用Inline合并
- 4个以上使用Footnote或Endnote
- 存在冲突时必须使用选项B或C格式

## 3. 来源质量矩阵应用规则

### 3.1 质量等级定义

| 等级 | 来源类型 | 权重 | 信任度 | 使用限制 |
|------|---------|------|--------|---------|
| **A** | 官方/权威 | 4 | 最高 | 可作为主要依据 |
| **B** | 学术/同行评审 | 3 | 高 | 可作为主要依据 |
| **C** | 行业报告/专业机构 | 2 | 中高 | 需交叉验证 |
| **D** | 主流媒体 | 1 | 中 | 需注明时效性 |
| **E** | 一般媒体/个人 | 0.5 | 低 | 仅作辅助参考 |
| **F** | 间接引用/无法追溯 | 0.25 | 最低 | 尽量避免使用 |

### 3.2 质量矩阵应用规则

**规则1 - 最低门槛**:
```
Fact类Claim: 至少1个A级或2个B级来源
Analysis类Claim: 至少2个来源（不限等级，但平均>=C）
Inference类Claim: 至少3个来源，或1个A级+1个B级
Assumption类Claim: 无强制要求，但间接参考需标注
```

**规则2 - 升级要求**:
```
影响重大的Claim（涉及决策建议、风险评估）:
  → 最低要求提升一级
  → 必须包含至少1个A级或B级来源
```

**规则3 - 降级处理**:
```
来源超过18个月未更新:
  → 质量等级降一级（A→B, B→C, 以此类推）
来源存在已知偏见:
  → 在引用中标注偏见标记，不影响等级但影响使用方式
```

## 4. 冲突来源的处理方式

### 4.1 冲突识别

以下情况视为来源冲突：
- 两个来源对同一事实给出矛盾数据
- 定性判断完全相反（如"有利"vs"不利"）
- 定量数据差异超过可接受范围（通常>5%）
- 时间序列趋势判断相反

### 4.2 冲突处理流程

```
Step 1: 确认冲突真实性（非误解/翻译差异/时间差异）
Step 2: 评估双方来源质量（应用来源质量矩阵）
Step 3: 按优先级规则处理:
  ├─ 差距>=2级 → 采纳高质量来源
  ├─ 差距<2级 → 保留冲突，writer需明确说明
  └─ 同等级 → 优先更新来源，仍冲突则保留
Step 4: 在Claim-Evidence Map中显式标注处理结果
```

### 4.3 冲突呈现格式

```markdown
**冲突标注示例**:

> 关于X政策的就业影响，来源间存在分歧：
> - [S1:A级, 人社部官方数据] 显示失业率下降0.3%
> - [S7:C级, 某智库报告] 认为短期就业压力增大
> - 处理: 采纳S1（官方数据优先），S7标注为"不同视角"在报告中说明
> - 状态: [resolved: favor_official]
```

### 4.4 禁止行为

- ✗ 隐藏反对证据
- ✗ 只引用支持自己结论的来源
- ✗ 将低质量来源包装成高质量来源
- ✗ 在冲突未解决时假装不存在冲突

## 5. 多来源合并引用规则

### 5.1 合并条件

可以合并引用的场景：
- 多个来源结论一致或互补
- 不同来源提供同一结论的不同侧面证据
- 形成证据链（来源A→来源B→来源C，层层递进）

不可合并引用的场景：
- 来源间存在未解决的冲突
- 来源质量差距>=2级且结论不同
- 间接引用试图冒充直接引用

### 5.2 合并格式

```markdown
一致性合并:
[S1, S3, S5: 一致认为"AI投资将持续增长"]
  └─ S1: 官方数据支撑
  └─ S3: 学术研究支撑
  └─ S5: 行业报告支撑

互补性合并:
[S1(宏观数据) + S3(微观调研): 共同支撑"就业市场分化"]
  └─ S1提供全国总体数据
  └─ S3提供行业细分数据

证据链合并:
[S2 → S4 → S6: 证据链]
  └─ S2: 技术可行性验证
  └─ S4: 小规模试点成功
  └─ S6: 大规模部署效果
```

### 5.3 引用密度要求

| Claim类型 | 最低引用数 | 推荐引用数 |
|-----------|-----------|-----------|
| Fact | 1 | 2 |
| Analysis | 2 | 3-4 |
| Inference | 2 | 3-5 |
| Assumption | 0（标注无直接引用） | 1（如有间接参考） |

## 6. Uncertainty标注语言规范

### 6.1 置信度用语表

| 置信度 | 推荐用语 | 避免用语 |
|--------|---------|---------|
| **High** | "数据显示..." "根据...确认" "有充分证据表明..." | "绝对" "毫无疑问" "100%确定" |
| **Medium** | "研究表明..." "有证据显示..." "分析表明..." | "证明" "证实" "已经确定" |
| **Low** | "初步迹象显示..." "有线索表明..." "可能暗示..." | "表明" "说明"（在高不确定性语境） |
| **Indeterminate** | "目前尚不清楚..." "缺乏足够信息判断..." "数据不足以..." | 不做判断或随意猜测 |

### 6.2 引用来源时的不确定性标注

当引用来源本身存在局限时：

```markdown
格式模板:
"据[S3:XX]报道/数据显示..."
"[S3]的作者认为...（注意：该来源可能存在YY偏见）"
"基于有限样本（n=XX），初步数据显示..."

完整示例:
"据[S3:摘要]报道，该政策在试点地区取得积极效果
（注意：S3为早期试点数据，样本量有限，长期效果有待观察）"
```

### 6.3 不确定性级别与语言对应

```
Level 1 - 几乎确定 (>90%):
  "数据显示..." "根据官方统计..." "已确认..."
  适用: High置信度的Fact

Level 2 - 很可能 (70-90%):
  "有充分证据表明..." "研究普遍认为..." "大多数数据显示..."
  适用: High置信度的Analysis/Medium-High的Inference

Level 3 - 可能 (50-70%):
  "有可能..." "部分研究表明..." "在某些条件下..."
  适用: Medium置信度的Analysis/Inference

Level 4 - 不确定 (30-50%):
  "初步迹象显示..." "有限数据表明..." "存在这种可能性..."
  适用: Low置信度的Inference

Level 5 - 极不确定 (<30%):
  "目前尚不清楚..." "数据不足以得出结论..." "需要进一步研究..."
  适用: Indeterminate或Assumption
```

### 6.4 标准不确定性表述模板

```markdown
模板1 - 单一来源:
"据[SX]报道，XX。但此为单一来源，需进一步验证。"

模板2 - 间接证据:
"基于[SX]和[SY]的间接推断，初步认为XX。直接证据尚不充分。"

模板3 - 数据有限:
"现有数据（SX, n=小样本）显示XX，但样本量有限，结论需谨慎对待。"

模板4 - 存在冲突:
"关于XX，[S1]认为A，[S2]认为B。两方来源质量分别为A级和C级，
目前采纳S1观点，但S2的反对意见值得关注。"

模板5 - 基于假设:
"在[假设A: 风险等级MEDIUM]成立的前提下，可以推断XX。
若假设不成立，则结论可能变化。"
```

## 7. 引用红线（v1.2强制）

- ✗ **不引用未实际查阅的来源** —— 每个引用必须实际阅读过
- ✗ **不转引二手资料而不标注** —— 尽量查原文，无法查到时标注"间接引用"
- ✗ **不截断引用改变原意** —— 引用必须保留原始上下文
- ✗ **不隐藏引用来源的局限性** —— 偏见、时效性、样本限制必须标注
- ✗ **不在冲突时选择性引用** —— 反对证据必须呈现
- ✗ **不将Assumption包装成有来源引用** —— Assumption必须标注"无直接引用"

## 8. 引用完整性自检清单

输出前检查：

- [ ] 每个核心Claim至少1个引用
- [ ] Analysis类Claim至少2个引用
- [ ] Inference类Claim展示了推理链上的所有引用
- [ ] Assumption明确标注"无直接引用"或有间接参考
- [ ] 冲突来源已显式呈现
- [ ] 每个引用都有来源编号
- [ ] 每个来源都有质量评级
- [ ] 存在偏见/局限的来源已标注
- [ ] 超过18个月的来源已检查时效性
- [ ] 间接引用已明确标注
