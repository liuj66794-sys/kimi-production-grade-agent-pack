# 不确定性表达规范

## 置信度等级与用语

| 等级 | 定义 | 推荐用语 | 避免用语 |
|------|------|---------|---------|
| **High** | 多源强一致，直接证据充分 | "数据显示..." "根据...确认" | "绝对" "毫无疑问" |
| **Medium** | 证据一致但有限，或间接证据 | "研究表明..." "有证据显示..." | "证明" "证实" |
| **Low** | 单一来源、间接证据、或存在冲突 | "初步迹象显示..." "有线索表明..." | "表明" "说明"（在高不确定性语境） |
| **Indeterminate** | 证据不足或矛盾无法判断 | "目前尚不清楚..." "缺乏足够信息判断..." | 不做判断或随意猜测 |

## 推论用语规范

### Inference表达模板
```
基于[证据集合]，在[假设条件]下，有[中/高]置信度认为[推论]。
若[假设]不成立，则替代判断为[替代推论]。
```

### 概率表达（如适用）
```
- "可能性较高" → 对应 >70% 置信区间
- "有可能" → 对应 50-70% 置信区间
- "不确定/难以判断" → 对应 <50% 或数据不足
```

## 不确定性必须声明的场景
1. 基于单一来源的结论
2. 间接证据链条（>2跳）
3. 存在冲突证据但未解决
4. 依赖关键假设
5. 领域本身存在争议

## 禁止表达
- "毫无疑问"
- "毫无疑问地证明"
- "所有人都知道"
- "显而易见"
- 任何绝对化表述用于Inference或Assumption
