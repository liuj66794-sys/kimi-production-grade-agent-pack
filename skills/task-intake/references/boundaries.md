# Task Intake 边界

## 适用范围
- 任何用户任务请求的第一步

## 不适用场景
- 已结构化的任务执行
- 纯工具调用（如文件读取）
- 闲聊或非任务对话

## 复杂度阈值
- 需要5个以上独立信息源 → 标记为swarm任务
- 涉及多个文件/格式/角色 → 标记为swarm任务
- 需要跨领域知识整合 → 标记为swarm任务
- 时间跨度超过单一阶段 → 标记为swarm任务

## 决策规则
| 条件 | 动作 |
|------|------|
| 单一工具可完成 | 直接执行，不标记swarm |
| 需要多步骤但单领域 | 标记为sequence，不标记swarm |
| 多领域/多角色/多源 | 标记为swarm任务 |
| 用户明确指定模式 | 遵循用户指定 |

## 最小字段检查
- [ ] goal 明确且可衡量
- [ ] deliverables 至少包含1项
- [ ] minimal_plan 至少3步
- [ ] need_* 布尔字段全部声明
