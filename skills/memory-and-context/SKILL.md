# Memory and Context Skill

## 目的
管理长期上下文信息，支持跨任务记忆恢复、用户偏好追踪和状态管理。

## 触发条件
- 需要恢复历史任务上下文
- 需要访问用户偏好设置
- 跨会话需要保持状态连续性
- 任务需要引用之前的交付物

## 输入
- 当前任务上下文
- 历史任务标识（如需恢复）
- 用户偏好查询

## 输出
- 恢复的历史上下文摘要
- 相关的历史交付物引用
- 用户偏好配置

## 工作流
1. 识别需要的上下文类型
2. 查询和检索相关记忆
3. 验证记忆的时效性和相关性
4. 整合到当前任务上下文
5. 输出上下文摘要

## 不负责
- 不替代具体任务Skill执行工作
- 不做新信息的研究或分析
- 不存储敏感个人信息（遵循隐私边界）
