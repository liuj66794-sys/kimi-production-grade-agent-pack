# Multimodal Analysis Skill

## 目的
分析非文本内容（图像、视频、音频），提取结构化信息，与文本证据整合。

## 触发条件
- 任务涉及图像、视频或音频分析
- 需要视觉内容理解或描述
- 多模态内容需要整合分析

## 输入
- 图像/视频/音频文件或URL
- 分析目标和问题
- 相关文本上下文（如有）

## 输出
- 结构化视觉/音频分析结果
- 与文本证据的关联标注
- 关键帧/片段提取建议

## 工作流
1. 加载和预处理多模态内容
2. 提取关键信息和特征
3. 与文本证据交叉验证
4. 输出结构化分析结果

## 不负责
- 不生成多模态内容（仅分析）
- 不替代deep-research做文本信息搜索
- 不做情感分析或主观审美判断（除非任务要求）
