# v4.2 Roadmap & Sprint Engine Specification

## 概述

Roadmap & Sprint Engine 管理项目路线图、里程碑和当前 Sprint 的状态。

---

## 路线图文件格式

### 文件位置

```
runtime/roadmap.json
```

### Schema

```json
{
  "roadmap_id": "string",
  "project_id": "string",
  "milestones": [
    {
      "id": "string",
      "name": "string",
      "status": "enum: planned, in_progress, completed, blocked",
      "target_version": "string (semver)"
    }
  ],
  "current_sprint": {
    "id": "string",
    "name": "string",
    "status": "enum: planned, in_progress, completed, blocked",
    "start_date": "YYYY-MM-DD",
    "end_date": "YYYY-MM-DD",
    "issues": "array of issue objects"
  },
  "last_updated": "ISO 8601 datetime"
}
```

---

## Milestone 状态定义

| 状态 | 含义 |
|------|------|
| planned    | 计划中的里程碑 |
| in_progress| 进行中的里程碑 |
| completed  | 已完成的里程碑 |
| blocked    | 被阻塞的里程碑 |

---

## Sprint 管理

### Sprint 生命周期

```
planned --> in_progress --> completed
    |
    v
blocked
```

### Issue 格式

```json
{
  "issue_id": "string",
  "title": "string",
  "status": "enum: open, in_progress, resolved, closed",
  "priority": "enum: critical, high, medium, low",
  "created_at": "ISO 8601 datetime",
  "resolved_at": "ISO 8601 datetime or null"
}
```

---

## 安全要求

1. **读取路线图**: A1 动作，无需审批
2. **更新里程碑状态**: A3 动作，需 HITL 审批
3. **创建 Sprint**: A4 动作，需 HITL 审批
4. **修改路线图结构**: A4 动作，需 HITL 审批

---

## 与 Project State 的关系

Roadmap 和 Project State 是两个独立的状态文件：

- `project-state.json`: 项目整体状态（autonomy level、anomaly counter 等）
- `roadmap.json`: 路线图和 Sprint 状态

更新 roadmap 时需要先通过 Autonomy Gate 评估。
