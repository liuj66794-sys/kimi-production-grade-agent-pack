# v2.2 Slide Maker Module Specification

## Overview

The Slide Maker module generates presentation content from user input.
It converts natural language requests, outlines, and data into structured
slide decks in Markdown-based or standard presentation formats.

## Architecture

```
User Query ("create a presentation about AI trends")
    |
    v
Orchestrator (L1)
    |
    +-- Detect slide intent --> Slide Maker Sub-Agent
    |                             |
    |   outline-slides(topic)     |
    |   ------------------->      |
    |                             |
    |   <-------------------      |
    |   SlideOutline[]            |
    |
    +-- Approve outline
    |
    +-- Generate content --> Slide Maker Sub-Agent
                                  |
            generate-slides(outline)
            ----------------------->
                                  |
            <-----------------------
            SlideDeck (markdown)
```

## Components

### Agent: slide-maker-sub
- **Version**: 2.2.0
- **Type**: Sub-agent
- **Tools allowed**: ReadFile, WriteFile, ReadMediaFile (for image inclusion)
- **Tools denied**: Shell, SearchWeb, FetchURL, BrowserVisit

### Skills
1. **slide-outline**: Generate structured outline from topic
2. **slide-content**: Generate slide content from approved outline
3. **slide-format**: Format slides for target output (markdown, HTML)

## Slide Structure

```json
{
  "slide_deck": {
    "title": "string",
    "subtitle": "string",
    "author": "string",
    "date": "string",
    "slides": [
      {
        "slide_number": "integer",
        "type": "title | content | two_column | image | data | section_divider | closing",
        "title": "string",
        "content": {
          "bullet_points": ["string"],
          "body_text": "string",
          "table": {
            "headers": ["string"],
            "rows": [["string"]]
          }
        },
        "image_path": "string (optional)",
        "speaker_notes": "string",
        "layout": "string"
      }
    ]
  }
}
```

## Workflow

### Phase 1: Outline Generation
1. User provides topic, audience, and duration (or defaults inferred)
2. Agent generates `slide-outline.json` with slide count and structure
3. User reviews and approves (or iterates)

### Phase 2: Content Generation
1. Agent generates full slide content per approved outline
2. Each slide has: title, content, optional speaker notes
3. Output saved as `slide-deck.md`

### Phase 3: Formatting (optional)
1. Convert markdown to target format if requested
2. Default output is structured markdown compatible with reveal.js, Marp, etc.

## Output Format — slide-deck.md

```markdown
---
title: "Presentation Title"
subtitle: "Subtitle"
author: "Author Name"
date: "2024-01-15"
---

<!-- Slide 1 -->
# Presentation Title
## Subtitle
Author Name | Date

---

<!-- Slide 2 -->
## Agenda
- Point 1
- Point 2
- Point 3

---

<!-- Slide 3 (two_column) -->
## Comparison

| Left Column | Right Column |
|-------------|-------------|
| Feature A   | Feature B   |

<!-- notes: Speaker notes for this slide -->
```

## Slide Types

| Type | Description | Use Case |
|------|-------------|----------|
| title | Title slide with branding | Opening |
| content | Bullets + body text | Main content |
| two_column | Side-by-side layout | Comparison |
| image | Full or partial image | Visual showcase |
| data | Table or chart reference | Data presentation |
| section_divider | Transition slide | Section breaks |
| closing | Summary + CTA | Ending |

## Hard-Fail Rules

| ID | Rule | Consequence |
|----|------|-------------|
| HF-SL-01 | Must not fabricate statistics or data — use provided data only | Termination |
| HF-SL-02 | Must generate outline before full content — no skipping | Termination |
| HF-SL-03 | Output must conform to slide-deck.schema.json | Termination |
| HF-SL-04 | Speaker notes must not repeat slide content verbatim | Termination |

## Constraints

1. **Max slides per deck**: 50 (prevent runaway generation)
2. **Max bullets per slide**: 7 (readability limit)
3. **Max bullet length**: 120 characters
4. **Max table rows**: 15 per slide
5. **Image references**: Must be local paths or data URIs only
6. **No external content**: Cannot fetch images or data from URLs

## Degradation Strategy

| Trigger | Action |
|---------|--------|
| User requests >50 slides | Cap at 50, warn user, suggest splitting into multiple decks |
| Insufficient content for outline | Generate placeholder slides with [TBD] markers |
| Complex data tables | Truncate to top N rows, note truncation in speaker notes |
| Missing image references | Generate placeholder text with [IMAGE: description] |

## Performance SLA

| Operation | Target | Timeout |
|-----------|--------|---------|
| Outline generation | <5s | 15s |
| Full deck generation | <30s | 60s |
| Format conversion | <2s | 10s |
