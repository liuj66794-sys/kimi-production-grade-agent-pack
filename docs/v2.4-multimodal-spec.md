# v2.4 Multimodal Module Specification

## Overview

The Multimodal module provides visual content analysis capabilities.
It analyzes images, screenshots, design mockups, and charts to extract
information, detect issues, and produce structured review reports.

## Architecture

```
User uploads image.png
    |
    v
Orchestrator (L1) detects image file
    |
    +-- Classify intent:
    |     - UI review? --> ui-screenshot-review
    |     - Chart data? --> visual-evidence-extraction
    |     - General analysis? --> multimodal-review
    |
    v
Multimodal Sub-Agent (read-only analysis)
    |
    +-- Read image via ReadMediaFile
    +-- Analyze visual content
    +-- Apply confidence annotations
    +-- Generate structured report
    |
    v
Deliverables:
- multimodal-review-report.md
- visual-evidence-extraction.json (for charts)
```

## Components

### Agent: multimodal-sub
- **Version**: 2.4.0
- **Type**: Sub-agent (read-only)
- **Tools allowed**: ReadMediaFile, ReadFile, Glob
- **Tools denied**: WriteFile, Shell, SearchWeb, FetchURL, BrowserVisit, GenerateImage

### Skills
1. **multimodal-review**: General visual content analysis
2. **ui-screenshot-review**: UI implementation quality review
3. **visual-evidence-extraction**: Chart/data visualization extraction

## Confidence Annotation System

All visual observations MUST include confidence markers:

| Level | Indicator | When to Use |
|-------|-----------|-------------|
| High | [confirmed] | Clearly visible, no ambiguity |
| Medium | [likely] | Visible but some detail unclear |
| Low | [uncertain] | May be present, partially visible or obscured |
| None | [not visible] | Cannot determine from the image |

## Analysis Categories

### UI Element Detection
- Buttons, inputs, dropdowns, modals, cards, tabs, navigation
- Text labels, headings, body copy
- Icons and iconography
- Form elements and states

### Layout Analysis
- Structure (grid, flexbox, fixed)
- Spacing and alignment
- Visual hierarchy
- Responsive behavior indicators

### Chart Data Extraction
- Chart type identification
- Axis label reading
- Value estimation from visual encoding
- Legend extraction

### Design Comparison
- Pixel-level differences
- Color accuracy
- Spacing accuracy
- Missing/extra elements

## Hard-Fail Rules

| ID | Rule | Consequence |
|----|------|-------------|
| HF-MM-01 | No hallucinated visual details | Termination |
| HF-MM-02 | No fabricated conclusions | Termination |
| HF-MM-03 | Visual uncertainty must be flagged | Termination |
| HF-MM-04 | No image modification (read-only) | Termination |
| HF-MM-05 | No external media fetching | Termination |

## Read-Only Constraint

The multimodal agent is **strictly read-only**. It cannot:
- Create or modify image files
- Generate new visual content
- Edit or annotate uploaded images
- Write files that contain image data

It can only:
- Read and analyze existing media files
- Write text-based analysis reports
- Output structured JSON with extracted data

## Degradation Strategy

| Trigger | Action |
|---------|--------|
| Image resolution too low | Analyze only clearly visible regions; request higher resolution |
| Image partially corrupted | Analyze undamaged portions; note corruption |
| Text too small | Mark as [not visible]; do not guess |
| Chart too dense | Provide approximate ranges; mark low confidence |
| Colors unclear | Describe relatively; avoid exact names |

## Output Schemas

- `schemas/multimodal-review.schema.json`: General review findings
- `schemas/visual-evidence.schema.json`: Chart data extraction results

## SLA

| Operation | Target | Timeout |
|-----------|--------|---------|
| Image analysis (standard) | <10s | 30s |
| Image analysis (high-res) | <20s | 45s |
| Chart data extraction | <15s | 30s |
| Design comparison (2 images) | <20s | 45s |

## Quality Thresholds

| Metric | Minimum Acceptable |
|--------|-------------------|
| Confidence annotation coverage | 100% of observations |
| [confirmed] accuracy | >95% (verified against ground truth) |
| [uncertain] rate | >10% of observations (conservative bias) |
| False positive rate (issues) | <5% |
