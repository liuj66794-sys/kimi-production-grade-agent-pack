# v4.1 Project State Engine Specification

## 概述

Project State Engine 是 L4 半自治系统的核心状态管理组件，负责维护项目长期状态并提供安全的原子更新机制。

---

## 状态文件格式

### 文件位置

```
runtime/project-state.json
```

### Schema

```json
{
  "project_id": "string",
  "name": "string",
  "current_stage": "string (enum: l1, l2, l3, l4)",
  "current_version": "string (semver)",
  "status": "string (enum: active, paused, degraded, halted)",
  "autonomy_level": "string (enum: a0, a1, a2, a3, a4, a5)",
  "autonomy_policy_version": "string",
  "hitl_enabled": "boolean",
  "context_budget": {
    "max_tokens": "integer",
    "hot_context_limit": "integer",
    "warm_context_limit": "integer",
    "protected_keys": "array of strings"
  },
  "anomaly_counter": {
    "degrade_count_24h": "integer",
    "pause_count_24h": "integer",
    "last_reset": "ISO 8601 datetime"
  },
  "pending_approvals": "array of approval objects",
  "completed_sprints": "array of sprint ids",
  "roadmap_ref": "string (file path)",
  "last_updated": "ISO 8601 datetime",
  "version": "integer (monotonically increasing)"
}
```

## 安全写入规则

### 1. 原子写入 (Atomic Write)

所有修改必须通过以下流程：

```python
def atomic_write_state(new_state, expected_version):
    """
    1. 读取当前状态，验证 version == expected_version
    2. 写入临时文件: project-state.json.tmp
    3. fsync 临时文件
    4. rename(临时文件, project-state.json)
    5. 返回成功/失败
    """
```

### 2. 版本冲突检查

写入时必须检查 version 是否匹配。如果不匹配，说明有其他并发修改，写入失败。

```python
class VersionConflictError(Exception):
    """version 不匹配，状态已被其他进程修改"""
```

### 3. Version 递增

每次成功写入后 `version += 1`。

### 4. 时间戳更新

每次写入后更新 `last_updated` 为当前 UTC 时间。

## 状态转换

```
active --> degraded (Anomaly Counter degrade_count >= 3)
active --> paused   (Anomaly Counter pause_count >= 5)
degraded --> active (24h 窗口重置且人工确认)
paused --> active   (人工确认 + 安全检查)
any --> halted      (系统关闭或严重错误)
```

## API

### read_state()

```python
def read_state() -> dict:
    """读取当前项目状态（只读）"""
```

### write_state()

```python
def write_state(new_state: dict, expected_version: int) -> bool:
    """
    原子写入新状态。
    
    Args:
        new_state: 新的完整状态对象
        expected_version: 预期的当前版本号
    
    Returns:
        True if 写入成功
    
    Raises:
        VersionConflictError: version 不匹配
    """
```

### update_field()

```python
def update_field(field_path: str, value: any, expected_version: int) -> bool:
    """
    安全地更新单个字段。
    
    Args:
        field_path: 点分隔的字段路径，如 "anomaly_counter.degrade_count_24h"
        value: 新值
        expected_version: 预期的当前版本号
    """
```

---

## Protected Fields

以下字段需要 A5 权限才能修改：

- `autonomy_level`
- `autonomy_policy_version`
- `hitl_enabled`
- `context_budget.protected_keys`
