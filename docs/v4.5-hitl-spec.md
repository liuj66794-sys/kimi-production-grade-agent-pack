# v4.5 Human-in-the-Loop (HITL) Specification

## 概述

HITL 系统为所有 A3+ 动作提供人类审批机制，确保 Agent 不会未经批准执行写入或高风险操作。

---

## 核心原则

1. **A3+ 必须审批**: 所有 A3、A4、A5 动作必须经 HITL 审批
2. **A5 不允许超时**: A5 高风险动作不允许 accepted_by_timeout 自动批准
3. **审批持久化**: Pending approvals 存储在 project-state.json 中
4. **Audit Log**: 所有审批操作记录到 audit log
5. **Default Reject**: 超时的 A3/A4 审批默认拒绝（不是接受）

---

## 审批流程

```
Agent 请求 A3+ 动作
       |
       v
Autonomy Gate 评估
       |
       v
require_approval -----> HITL 系统创建 pending approval
                               |
                               v
                         显示审批请求
                               |
                    +----------+----------+
                    |          |          |
                    v          v          v
                 Approve    Reject    Defer
                    |          |          |
                    v          v          v
                 执行动作   拒绝动作   保持 pending
                    |          |          |
                    v          v          v
               记录日志   记录日志   等待后续处理
```

---

## 审批状态

| 状态 | 含义 |
|------|------|
| pending  | 等待审批 |
| approved | 已批准，可以执行 |
| rejected | 已拒绝，不可执行 |
| deferred | 推迟，保持 pending |
| timeout  | 超时，默认拒绝 |

---

## auto_accept_eligible 规则

```python
def is_auto_accept_eligible(action_level: str) -> bool:
    """
    只有 A1 和 A2 只读动作才能超时自动接受。
    A3+ 动作不允许自动接受。
    """
    return action_level in ["a1", "a2"]
```

## 安全约束

1. A5 动作的 auto_accept_eligible 必须为 false
2. 超时的 A3/A4 默认拒绝，不是接受
3. 所有审批响应记录 audit log
4. 审批响应必须包含 responder 标识
5. Defer 不改变状态，只更新时间戳
