# L4 Pre-Specification v4.0

## 目标

定义 Kimi Production-Grade Agent System v4.x L4 半自治项目组织层的整体架构和设计理念。

---

## 设计理念

### 安全第一

L4 半自治系统的核心设计哲学是 **安全优先于效率**。宁可误 block、误拒绝，也不允许静默越权。

### Defense in Depth

多层防护机制：
1. **A0 完全禁止层**: 绝对红线
2. **A1/A2 只读层**: 默认安全的行为
3. **A3/A4 HITL 审批层**: 写入操作需人类确认
4. **A5 显式批准层**: 高风险操作需显式人类批准
5. **Anomaly Counter**: 异常行为自动降级/暂停

## 数据流

1. Agent 请求动作
2. Autonomy Gate 评估
3. 如通过 → 执行
4. 如需审批 → HITL 创建 pending approval
5. 人类审批 → 执行或拒绝
6. 所有决策记录 audit log
7. Anomaly Counter 监控异常模式

## 风险评估

| 风险 | 缓解措施 |
|------|----------|
| Agent 静默越权 | Default deny + Autonomy Gate |
| Agent 绕过审批 | A0 禁止 + forbidden patterns |
| HITL 超时绕过 | A5 不允许 timeout accept |
| Context 截断安全配置 | Protected keys 机制 |
| 异常行为不被发现 | Anomaly Counter 自动降级 |
