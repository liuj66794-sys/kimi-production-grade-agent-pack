# v2.3 Spreadsheet Module Specification

## Overview

The Spreadsheet module provides expert-level CSV/Excel data analysis capabilities.
It reads tabular data, computes statistics, detects anomalies, checks data quality,
and generates structured analysis reports.

## Architecture

```
User uploads data.csv
    |
    v
Orchestrator (L1) detects .csv/.xlsx extension
    |
    +-- Handoff --> Spreadsheet Sub-Agent
                      |
                      +-- Read file (pandas)
                      +-- Compute summary statistics
                      +-- Detect missing values
                      +-- Detect outliers (IQR / Z-score)
                      +-- Check data quality
                      +-- Generate reports
                      |
                      v
              Deliverables:
              - analysis-report.md
              - data-quality-report.md
              - processed-{timestamp}.csv (if transformed)
              - JSON results (schema-validated)
```

## Components

### Agent: spreadsheet-sub
- **Version**: 2.3.0
- **Type**: Sub-agent
- **Tools allowed**: ReadFile, WriteFile, Shell (CSV/Excel scripts only)
- **Tools denied**: SearchWeb, FetchURL, BrowserVisit

### Skills
1. **spreadsheet-analysis**: Full data analysis pipeline
2. **table-summary**: Human-readable data description
3. **data-quality-check**: Quality dimension assessment

## File Format Support

| Format | Extension | Read | Write | Notes |
|--------|-----------|------|-------|-------|
| CSV | .csv | Yes | Yes | UTF-8 default, auto-detect encoding |
| Excel | .xlsx | Yes | Yes | Requires openpyxl |
| Excel Legacy | .xls | Yes | No | Requires xlrd |
| TSV | .tsv | Yes | Yes | Tab-separated |

## Analysis Pipeline

### Step 1: File Ingestion
- Detect encoding (UTF-8 → GBK → Latin-1)
- Parse with pandas
- Validate non-empty file
- Record file metadata (size, rows, columns)

### Step 2: Column Profiling
For each column:
- Infer data type (numeric, string, datetime, boolean, mixed)
- Count nulls and compute null ratio
- Count unique values
- Compute type-appropriate statistics

### Step 3: Missing Value Analysis
- Per-column null count and ratio
- Identify columns with >50% nulls as "incomplete"
- Row-level completeness check

### Step 4: Outlier Detection
- IQR method: flag values outside [Q1-1.5*IQR, Q3+1.5*IQR]
- Z-score method: flag values with |z| > 3.0
- Report outlier count, ratio, and example values

### Step 5: Data Quality Assessment
Three dimensions scored 0-100:
- **Completeness** (weight 0.4): Missing data coverage
- **Consistency** (weight 0.3): Format and type uniformity
- **Accuracy** (weight 0.3): Value plausibility and range

### Step 6: Report Generation
- `analysis-report.md`: Full analysis with all statistics
- `data-quality-report.md`: Quality dimension scores and issues
- `table-summary.md`: Human-readable narrative summary
- JSON outputs validated against schemas

## Performance & Degradation

| Trigger | Degradation Action |
|---------|-------------------|
| File > 100MB | Streaming read with sampling |
| Rows > 1M | Sample: first 10K + random 10K + last 1K |
| Columns > 500 | Analyze first 500, note truncation |
| Out of memory | Chunked processing with sampling |
