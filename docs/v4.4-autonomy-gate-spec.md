# v4.4 Autonomy Gate Specification

## 概述

Autonomy Gate 是 L4 半自治系统的核心安全门控组件。它评估每个 Agent 动作请求，根据动作分级、allowlist、forbidden patterns 和异常计数器做出 allow/block/require_approval 决策。

**核心原则: Default Deny**

---

## 决策流程

```
                    动作请求
                       |
                       v
            +---------------------+
            | 1. Check forbidden  |
            |    patterns         |
            +---------------------+
                       |
              匹配? ----+---- 不匹配
               |              |
               v              v
            BLOCK     +---------------------+
                      | 2. Check A2         |
                      |    allowlist        |
                      +---------------------+
                                 |
                    A2 & 不在列表? -+-- 通过
                          |              |
                          v              v
                       BLOCK      +---------------------+
                                 | 3. Check autonomy   |
                                 |    level            |
                                 +---------------------+
                                            |
                               不允许? ------+---- 允许
                                 |                  |
                                 v                  v
                              BLOCK         +---------------------+
                                            | 4. Check anomaly    |
                                            |    counter          |
                                            +---------------------+
                                                       |
                                          超出阈值? ---+--- 正常
                                            |              |
                                            v              v
                                         BLOCK      +---------------------+
                                                   | 5. Route decision     |
                                                   +---------------------+
                                                              |
                              +----------+----------+----------+----------+
                              |          |          |          |          |
                              v          v          v          v          v
                            A0/A1      A2         A3         A4         A5
                              |          |          |          |          |
                              v          v          v          v          v
                            ALLOW     ALLOW    REQUIRE   REQUIRE   REQUIRE
                                              APPROVAL  APPROVAL  APPROVAL
                                                         (hitl)   (explicit_human)
```

    """

            "actor": str,

## Forbidden Patterns

以下模式匹配的动作直接被 block：

```
write_*_without_approval
modify_autonomy_*
delete_audit_*
bypass_gate
approve_memory
execute_shell
publish_release
```

匹配规则：使用 fnmatch 风格通配符匹配。

## Autonomy Level 检查

```python
LEVEL_HIERARCHY = {
    "a0": 0, "a1": 1, "a2": 2, "a3": 3, "a4": 4, "a5": 5
}

def level_allows_action(current_level: str, action_level: str) -> bool:
    return LEVEL_HIERARCHY[current_level] >= LEVEL_HIERARCHY[action_level]
```

## Anomaly Counter 检查

```python
def check_anomaly(anomaly: dict, action_level: str) -> bool:
    if anomaly["pause_count_24h"] >= 5:
        return False  # 完全暂停
    if anomaly["degrade_count_24h"] >= 3 and action_level in ["a3", "a4", "a5"]:
        return False  # 限制 A3+
    return True
```

## 安全约束

1. **Default Deny**: 未识别的动作级别 → block
2. **Forbidden 优先**: 即使动作在 allowlist 中，匹配 forbidden pattern → block
3. **Level 严格检查**: 不允许 level 0 执行任何动作（包括 A0 的误用）
4. **Anomaly 优先**: Anomaly counter 超出阈值时，即使正常动作也应评估是否降级
